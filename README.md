# Calculator App!

Welcome to my calculator project! This is a project built with React.js and Tailwind CSS to practice creating an interactive application with basic mathematical operations.

---
## Features 

- 📱 Responsive design.
- 💅 Custom styles using Tailwind CSS.
- ✨ Basic operations: addition, subtraction, multiplication, division.
- 🔢 Automatic number formatting with thousand separators.
- ✅ Functions such as clear (AC) and delete (DEL).

---
## Technologies Used

-  **React.js:** Library for building user interfaces.
-  **Tailwind CSS:** CSS framework for styling.
-  **Vite:** Fast build tool for modern frontend projects.

---

## Installation

Follow these steps to run the project locally:

### Clone the repository:
```bash
git clone https://github.com/yourusername/calculator-app.git
cd calculator-app


### Install dependencies:

npm install
# or
yarn install

### Start the application:

npm run dev
# or
yarn dev


The app will be available at [http://localhost:5173](http://localhost:5173).
